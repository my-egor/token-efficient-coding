# Token-efficient coding

Локальный скилл для Codex, который маршрутизирует задачи разработки к минимально достаточной модели и сокращает лишний контекст.

## Возможности

- `SMALL` выполняется без субагентов.
- `MEDIUM` использует не более одного изолированного исполнителя, если делегация действительно уменьшает общий объём работы.
- `HIGH` отправляется сильной модели только при архитектурном, security-sensitive, миграционном или существенно неопределённом изменении.
- Субагент получает краткое задание вместо всей истории диалога.
- Исправления продолжаются у того же агента через `followup_task`.
- Факты проверяются тестами, сборкой, typecheck, линтером и `git diff`.
- Скилл не использует Jev, Java, API-ключи, MCP или внешние сервисы.

## Активация

```text
$token-efficient-coding
```

или:

```text
включи режим экономии
```

Режим действует только в текущей задаче. Обычный разговор об экономии токенов сам по себе скилл не включает.

## Принцип маршрутизации

| Уровень | Когда используется | Действие |
| --- | --- | --- |
| `SMALL` | Локальная низкорисковая правка | Главный агент работает сам |
| `MEDIUM` | Обычная функция, bounded debugging, несколько связанных файлов | Один изолированный исполнитель нижнего достаточного уровня |
| `HIGH` | Архитектура, авторизация, безопасность, миграции или сильная неопределённость | Сильный исполнитель; повышение только по доказанной причине |

Скилл не обещает конкретный процент экономии: фактический расход зависит от модели, проекта, числа попыток и объёма проверок.

## Установка

Скопируйте папку `token-efficient-coding` в `%USERPROFILE%\.codex\skills\token-efficient-coding` и перезапустите Codex, если новый скилл не появился сразу.

## Состав

```text
token-efficient-coding/
├── SKILL.md
├── README.md
└── agents/
    └── openai.yaml
```

Это instruction-only скилл: исполняемых скриптов и внешних зависимостей нет.

## Безопасность

Скилл не расширяет полномочия пользователя. Публикация, удаление, изменение доступов, работа с секретами и другие внешние действия требуют отдельного разрешения и должны выполняться по правилам Codex.

## Проверка

Структуру можно проверить официальным `quick_validate.py` из `skill-creator`. Если в среде отсутствует PyYAML, проверьте frontmatter, метаданные, активационные команды, плейсхолдеры и список файлов вручную.
